# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or pull
requests.

If GitHub's private vulnerability reporting feature is enabled for this
repository, use the repository's Security tab to report the issue privately.

If private vulnerability reporting is unavailable, contact the repository
owner privately through their GitHub profile before sharing technical details.
Do not publish exploit details while the issue is being reviewed.

## What to include

Please provide, where possible:

- A description of the vulnerability and its potential impact.
- Steps to reproduce it in a safe test environment.
- Relevant versions and sanitized logs.
- Any suggested mitigation.

Never include real passwords, API keys, encryption keys, personal information,
or production data in a report.

## Scope and response

Memora's maintainer will review reports and determine appropriate next steps.
Please allow reasonable time for investigation before publicly disclosing
a suspected vulnerability.

No response time or particular resolution is guaranteed.
